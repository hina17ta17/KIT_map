# KIT MAP

金沢工業大学 **扇が丘キャンパス**の案内サイト。
現在地から目的の建物・教室までの経路を案内する。

```powershell
npm install
npm run dev      # http://localhost:3000
```

| URL | 中身 |
|---|---|
| `/` | 作図ツール（地図データを作る画面） |
| `/test` | 地図が表示されないときの診断ページ |

## いま何を作っているか

**フェーズ1：現在地から目的地までの経路案内。**
ログイン不要・データベース不要・費用0円。

Google Directions API は構内の通路も教室も知らないため使えない。
経路は**チェックポイントと接続で作った自前のグラフ**を A* で解いて求める。

## 進捗

- ✅ 敷地の外周（1件・18頂点）
- ✅ 建物・屋外（38件・全件命名済み）
- ⏳ チェックポイントと接続（入力待ち）
- ❌ 経路探索の実装

## 技術

MapLibre GL JS ／ 国土地理院タイル ／ Next.js ／ Tailwind CSS

**契約が必要な有料APIは1つも使っていない。** 従量課金も発生しない。

## 出典

地図・航空写真に[地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)を使用。
画面内の出典表示は**消さないこと**（利用規約上の義務）。
