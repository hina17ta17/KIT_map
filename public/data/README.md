# 地図データ（静的ファイル）

Phase 1 はデータベースを使わない。地図データはすべてこのフォルダに GeoJSON として置き、
CDN から配信する。作図ツール（`/`）で書き出したファイルをここに保存する。

## ファイル一覧

| ファイル | 内容 | 状態 |
|---|---|---|
| `campus.geojson` | キャンパス敷地の外周ポリゴン | 作図中 |
| `buildings.geojson` | 建物ポリゴン（号館ごと） | 作図中 |
| `paths.geojson` | 構内の歩行者通路（LineString） | 未着手 |
| `entrances.geojson` | 建物の出入口（Point） | 未着手 |
| `rooms.geojson` | 教室（Point） | 未着手（屋内STEPで） |
| `nav_nodes.geojson` | 経路グラフのノード | 未着手 |
| `nav_edges.json` | 経路グラフのエッジ | 未着手 |
| `floors/` | フロア図画像 | 未着手（屋内STEPで） |

## 座標系

すべて **EPSG:4326（WGS84 / 経度・緯度の順）**。GeoJSON の標準に従う。

## campus.geojson

```jsonc
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": { "type": "Polygon", "coordinates": [[[136.62, 36.53], ...]] },
      "properties": { "name": "キャンパス敷地" }
    }
  ]
}
```

用途：圏内／圏外の判定（`turf.booleanPointInPolygon`）。

## buildings.geojson（建物・屋外設備）

```jsonc
{
  "type": "Feature",
  "geometry": { "type": "Polygon", "coordinates": [[...]] },
  "properties": {
    "tempId":   "B-01",  // 仮ID。作図順に自動採番。名称が判明しても変更しない
    "category": "hall",  // 種別。下の表を参照
    "code":     "23",    // 号館番号。category が "hall" のときだけ使う
    "name":     "23号館", // 表示名。目的地の検索対象になる
    "floors":   4,       // 階数。0 = 未確認。屋外では使わない
    "note":     ""       // 現地確認時のメモ
  }
}
```

### category（種別）

号館だけが目的地とは限らないため分類する。地図上の色もこれで決まる。

| 値 | 表示 | 例 | 号館番号 | 階数 | 色 |
|---|---|---|---|---|---|
| `hall` | 号館 | 23号館 | あり | あり | 青 |
| `facility` | 施設 | 図書館 / 体育館 / 食堂 / 夢考房 | なし | あり | 紫 |
| `outdoor` | 屋外 | グラウンド / 自転車小屋 / 駐車場 | なし | なし | 緑 |
| `other` | その他 | 門 / 掲示板 / 未分類 | なし | なし | 灰 |

`category` が無い古いデータは読み込み時に自動で補われる
（`code` があれば `hall`、`name` だけなら `facility`、どちらも無ければ `other`）。

### ★ 仮IDの運用ルール

大学からの建物一覧を待たずに作図を進めるため、**先に形だけ描いて仮IDを振る**。

```
STEP 1  作図ツールで全建物のポリゴンを描く    → B-01, B-02, B-03 ... が自動で振られる
STEP 2  現地を歩いて看板を確認する            → B-01 = 1号館、B-02 = 12号館 ... と判明
STEP 3  ツール上で「号館番号」を入力する       → code / name が埋まる
```

**`tempId` は一度振ったら変更しない。** 他のデータ（出入口・経路ノード）から参照するため、
後から採番し直すと参照が壊れる。号館番号は `code` に入れる。

## 作業の保存について

作図ツールでの作業内容は**ブラウザの localStorage に自動保存**される
（キー: `kitmap.draft.v1`）。ただしブラウザのデータを消すと失われるため、
**区切りがついたら必ず書き出してこのフォルダに置き、git にコミットすること。**

## 出典表示の義務

ベースマップと航空写真に国土地理院タイルを使用している。
アプリの画面内に「地理院タイル」の出典表示を必ず残すこと（MapLibre の attribution で表示中）。

トレース元にも地理院の航空写真を使う。これにより許諾の問題が発生しない。
**Google マップの航空写真をトレース元にしてはいけない**（規約違反）。
