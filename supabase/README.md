# データベースの定義について

このフォルダの `.sql` は、**意図的に GitHub へ置いていません**（`.gitignore` で除外）。

## なぜ置かないか

- 表の設計・権限の決まり（RLS）・関数の中身が、そのまま読めてしまう
- 学科や課外活動といった、大学から預かった情報も含まれる
- **動かすのに要るのは、Supabase へ流したあとの状態**であって、このファイルではない

一度実行すれば定義はデータベースの中に保管されるため、ここに無くてもサイトは動く。

## 手元にあるファイル

| ファイル | 中身 |
|---|---|
| `schema.sql` | 土台（利用者・教室・時限・食堂の器） |
| `migrations/002〜011` | あとから足した分。番号順に実行する |
| `setup.sql` | 002〜011 をつないだもの。貼り付け1回で済む |
| `first_admin.sql` | 最初の1回だけ。操作パスワードと管理者を決める |

## 新しく作り直すとき

1. Supabase の SQL Editor で `schema.sql` を実行
2. 続けて `setup.sql` を実行
3. 最後に `first_admin.sql` を実行（2か所を自分の値に書き換える）

## 学科・課外活動の登録データ

`migrations/003` に入っている登録データは、Word から機械的に作ったもの。
作り直したいときは、リポジトリ直下でこれを実行する。

```
node scripts/extract-docx.mjs 学科情報.docx 課外活動一覧.docx --sql supabase/seed_local.sql
```

書き出し先も `.gitignore` に入れてあるので、GitHub には上がらない。

## 保管について

このフォルダごと失うと、データベースを作り直す手順が無くなる。
GitHub に置かない代わりに、**別の場所に控えを取っておくこと**。
