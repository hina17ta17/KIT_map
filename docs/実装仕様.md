# 実装に必要な情報

フェーズ1（経路案内）を実装するために必要なものを、
**① 待たないと始められないもの** と **② 既定値で進められるもの** に分けた。

---

# ① 待たないと始められないもの

## データ（作図ツールで作る）

| 必要なもの | 現状 | 無いとどうなる |
|---|---|---|
| `campus.geojson` | ✅ 1件・18頂点 | — |
| `buildings.geojson` | ✅ 38件・全件命名済み | — |
| **`checkpoints.geojson`** | ❌ **0件** | **経路の節点が無く、探索が動かない** |
| **`links.geojson`** | ❌ **0件** | **通れる区間が無く、探索が動かない** |
| `rooms.json` | ❌ 0件 | 「302は3階です」が出ないだけ。経路は動く |

**チェックポイントと接続が無いと、実装しても動かすものが無い。** これだけが本当のブロッカー。

### 最低限の目安

| | 数 | 理由 |
|---|---|---|
| チェックポイント | **30〜60個** | 建物38件の出入口＋交差点・曲がり角 |
| 接続 | **40〜80本** | 網目にするので節点数より少し多くなる |

**完成させなくてよい。** 5〜10個つないだ時点で経路探索は動かせる。
動かしてから足りない所を足す方が速い。

### 実装が読むフィールド

これらが埋まっていないと動かない。

```
checkpoints  id / kind / radius / linkedTo / 座標
links        id / from / to / kind / enabled
buildings    tempId / name / code / category
campus       Polygon
rooms        buildingId / code / floor        （任意）
```

- **`linkedTo` が空のCPは到着判定に使われない**（通過点としては機能する）
- **`enabled: false` の接続は探索から除外される**

# ② 既定値で進められるもの

**指定が無ければ以下で実装する。** 変えたい項目だけ言ってもらえればよい。

## 距離と時間

| 項目 | 既定値 | 根拠 |
|---|---|---|
| 歩行速度 | **分速 80m** | 不動産表示の基準。構内なら妥当 |
| 所要時間の丸め | 切り上げ・分単位 | 「徒歩4分」 |
| 距離の丸め | 10m単位 | 「120m」 |

## 現在地の扱い

| 項目 | 既定値 | 理由 |
|---|---|---|
| 取得方法 | `watchPosition`（追従） | 歩きながら更新する |
| `enableHighAccuracy` | `true` | 構内では精度が要る |
| **accuracy ≤ 20m** | 信頼して表示 | |
| **accuracy ≤ 50m** | 円だけ出す（点は薄く） | おおよその位置 |
| **accuracy > 50m** | **採用しない**（前の位置を維持） | 誤った案内を出さない |
| 判断できないとき | **前の状態を維持** | 境界でのちらつきを防ぐ |

## 圏内／圏外

| 項目 | 既定値 |
|---|---|
| 判定 | `campus.geojson` に対する内外判定 |
| 圏外のとき | **地図は見せる。「圏外」と表示し現在地機能を止める** |
| 圏外からの経路検索 | **起点を手動で指定できるようにする**（門を既定にする） |

## 経路探索

| 項目 | 既定値 | 理由 |
|---|---|---|
| アルゴリズム | **A\***（`ngraph.path`） | |
| コスト | 距離 × 種別の重み | 主要1.0 / 一般1.2 / 細道1.6 / 階段1.5 |
| **現在地→最寄りCP** | **50m以内**のCPに接続 | 遠すぎると経路が不自然になる |
| 50m以内にCPが無い | 「近くに経路がありません」と表示 | 嘘の経路を出さない |
| 目的地 | その建物に紐づく **`entrance` のCP** | 複数あれば最も近いもの |
| 経路から外れたら | **30m 離れたら再計算** | 頻繁すぎると落ち着かない |

## 案内文

| 項目 | 既定値 |
|---|---|
| 曲がりの判定 | **30度未満は「直進」に統合** |
| 左右の判定 | 30〜120度＝右折／左折、120度超＝Uターン |
| 短区間の統合 | **10m未満は前後にくっつける** |
| 目印 | **50m以内で最も近い建物名**を使う（「12号館の角を右折」） |
| 階段 | 「階段を上る（2階分）」と**回数でまとめる** |
| 到着後 | 部屋があれば「302 は 3階です」を追記 |

## 到着判定

| 項目 | 既定値 |
|---|---|
| 判定 | CPの `radius` 以内に入ったら |
| 連続確認 | **3秒以上**入っていたら確定 | 一瞬の誤差で誤判定しない |
| 表示 | 「23号館に到着しました」＋部屋の階 |

## 検索

| 項目 | 既定値 |
|---|---|
| ライブラリ | **fuse.js**（あいまい一致） |
| 対象 | 建物名 / 号館番号 / 部屋番号 / 部屋名 |
| 表記ゆれ | `23・302` `23-302` `23302` `23 302` すべて一致 |
| 並び | 完全一致 → 前方一致 → あいまい |

## 経路の見た目

Googleマップ風に線を3枚重ねる。

```js
① 光彩   line-color #4285F4 / width 18 / opacity 0.25 / blur 8
② 白縁   line-color #ffffff / width 10
③ 本線   line-color #4285F4 / width 6
```

`line-cap: round` / `line-join: round`。
案内中は `line-dasharray` をずらして進行方向へ流す。

# ④ 判断が要るもの（既定値はあるが確認したい）

| 論点 | 既定 | 別案 |
|---|---|---|
| **雨ルート／バリアフリーの切り替え** | **出さない**（データが揃ってから） | 最初から切り替えボタンを置く |
| **コンパス（方位）** | **使わない** | 地図を進行方向に回す（iOSは許可が要る） |
| 到着後の画面 | 「到着しました」を出して案内終了 | 建物の写真や入口の説明を出す |
| 経路の候補 | **1本だけ出す** | 複数出して選ばせる |
| 検索候補の件数 | 上位8件 | もっと出す |

**言われなければ「既定」で実装する。** 後から変えられる範囲。

# ⑤ 実装の順番

データが揃ったら上から順に作る。**各段階で動く状態になる。**

| # | 作るもの | 依存 | これができると |
|---|---|---|---|
| 1 | 地図の表示（作図UIを外した閲覧モード） | 済んだデータ | 建物が見られる |
| 2 | 現在地の取得・表示・精度円 | なし | 自分の位置が出る |
| 3 | 圏内／圏外の判定 | campus | 「圏外」が出る |
| 4 | 目的地の検索 | buildings / rooms | 「23号館」で引ける |
| 5 | 経路グラフの構築 | **checkpoints / links** | — |
| 6 | A\* で最短経路 | 5 | 経路が計算できる |
| 7 | 光る経路の描画 | 6 | **見た目が完成する** |
| 8 | 案内文の生成 | 6 | 手順が出る |
| 9 | 到着判定 | checkpoints | 「到着しました」 |

**2〜4 は checkpoints / links が無くても作れる。**
データを待つ間に先に進められる部分。
