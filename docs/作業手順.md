# 作図ツールの使い方

```powershell
npm install     # 初回のみ
npm run dev
```

`http://localhost:3000` を開く。左パネル上部の黒枠に「次にやること」が常に出る。

作業内容は自動保存されるが、**ブラウザのデータを消すと失われる。**
区切りごとに書き出して `public/data/` に置くこと。

## 4. チェックポイントを置く

**[CPを置く]** → 地図をクリックするたびに1つ置かれる。

置く場所：

- [ ] 各建物の**出入口**（最重要。到着判定に使う）
- [ ] **交差点・曲がり角**（CP間は直線で結ばれるので角が必要）
- [ ] キャンパスの**門**

置いた直後に編集パネルが開くので、**名前**と**到着とみなす場所**を設定する。

## 5. CP同士をつなぐ

**[CP同士をつなぐ]** → チェックポイントを2つ順に押す。

```
CP1 を押す → 「C-01 を選択中」
CP2 を押す → C-01 ↔ C-02 が接続される
CP3 を押す → C-02 ↔ C-03 が接続される   ← 起点が自動で進む
```

押し続けるだけで数珠つなぎに引ける。分岐したいときは [起点を解除]。

**「✓ すべてのチェックポイントがひと続きにつながっています」が緑になるまで続ける。**

赤い警告が出たら、切り離されているCPを本体につなぐ。

## 6. 現地確認

`現地調査.md` を参照（このリポジトリには入れていない。設計フォルダ側にある）。
要点だけ再掲：

| 取るもの | 何のため | 優先 |
|---|---|---|
| **出入口の位置** | 到着判定・案内の終点 | 🔴 必須 |
| **通れるかどうか** | 通れない区間は `enabled: false` にする | 🔴 必須 |
| **建物名の答え合わせ** | 38件は推測。看板と突き合わせる | 🔴 必須 |
| 屋根の有無 | 雨の日ルート | 🟡 |
| 階段・段差 | バリアフリー経路 | 🟡 |

**建物に入る必要はない。** 屋内は対象外。

## 7. 書き出す

```powershell
# ダウンロードした .geojson / .json を public/data/ へ
Move-Item "$env:USERPROFILE\Downloads\*.geojson" "public\data\" -Force
Move-Item "$env:USERPROFILE\Downloads\rooms.json" "public\data\" -Force
```

## 精度の扱い（推測で決めない）

`accuracy` の値で3状態に分ける。**判断できないときは前の状態を維持する**
（境界でのちらつきを防ぐため）。

| accuracy | 扱い |
|---|---|
| ≤ 20m | 信頼する |
| ≤ 50m | おおよその位置として扱う |
| > 50m | 採用しない |

## 光る経路の描き方

線レイヤを3枚重ねる。

```js
// ① 外側の光彩
{ "line-color": "#4285F4", "line-width": 18, "line-opacity": 0.25, "line-blur": 8 }
// ② 白い縁取り
{ "line-color": "#ffffff", "line-width": 10 }
// ③ 本線
{ "line-color": "#4285F4", "line-width": 6 }
```

`line-cap: round` / `line-join: round` を付ける。
`line-dasharray` を毎フレームずらすと進行方向へ流れる光になる。

## 手順の文章化

道を素直に辿ると「5m直進、右に3度、8m直進…」と細切れになる。まとめる。

| 処理 | 内容 |
|---|---|
| 角度の閾値 | 30度未満は曲がりとみなさず「直進」に統合 |
| 短区間の統合 | 10m未満の区間は前後にくっつける |
| ランドマーク化 | 「12号館の角を右折」と近くの建物名で言う |
